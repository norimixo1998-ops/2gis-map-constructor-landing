# Изображения карточек «Решаемые задачи»

Кладите готовые коллажи карт в эту папку. Для каждого лендинга используйте отдельный префикс и порядковый номер: например, `geoflow-logistics-01.webp`, `geoflow-logistics-02.webp` (для варианта из четырёх карточек также `-03.webp` и `-04.webp`).

Затем в данных страницы передайте `imageSrc: "/images/solved-tasks/geoflow-logistics-01.webp"` для соответствующей карточки. Для отдельной мобильной композиции используйте `mobileImageSrc`. Пока `imageSrc` отсутствует, компонент показывает плейсхолдер из Figma. На десктопе изображение вписывается целиком (`object-fit: contain`), на мобильном заполняет слот (`object-fit: cover`). Для смыслового изображения укажите `imageAlt`. Если имя файла содержит пробел, кодируйте его как `%20` в `mobileImageSrc`, который попадает в `srcSet`.
