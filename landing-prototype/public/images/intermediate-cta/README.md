# Иллюстрации промежуточного CTA

Текущие файлы: `desktop_image.png` и `mobile_image.png`. Пути в данных страницы: `/images/intermediate-cta/desktop_image.png` и `/images/intermediate-cta/mobile_image.png`.

Экспортируйте только иллюстрацию с прозрачным фоном. Зелёная карточка, текст и кнопки создаются компонентом. Десктопное изображение занимает правую область карточки, мобильное — область между описанием и кнопкой. При замене PNG сохраняйте имена файлов либо обновляйте пути в данных страницы. Проверяйте кадрирование на 375, 768 и 1440 px.
