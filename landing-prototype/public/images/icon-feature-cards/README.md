# Иконки для S06

Пять SVG экспортированы из [макета IconFeatureCards](https://www.figma.com/design/2GackEUWd1sfbXBU0OUElS/Конструктор?node-id=294-12813): `route-mini-map.svg`, `map-pins.svg`, `clock.svg`, `tuning-right.svg`, `layers.svg`. Они используются в предпросмотре. Для нового лендинга передайте каждой карточке утверждённый `iconSrc`; не выводите произвольную иконку вместо отсутствующего материала.

В блоке S05 на странице акции используются белые SVG размером 48 × 48 px: `image-stroke.svg` для веб-панели администратора, `point-top-right-to-bottom-left-fill.svg` для мобильного приложения сотрудника и `globe-stroke.svg` для публичного API.
