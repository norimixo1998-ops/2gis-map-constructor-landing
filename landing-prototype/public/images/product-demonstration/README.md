# Изображения демонстрации продукта

Складывайте сюда два вида файлов: запечённый декоративный фон блока (`background.desktop` и `background.mobile`) и изображение интерфейса конкретного продукта (`image.desktop` и `image.mobile`). Пути задаются в `content/<имя-страницы>.ts` относительно `/public`. Сейчас в папке находятся только фоны `light_desktop.png` и `Light_mobile.png`; текущий блок показывает плейсхолдер. Для нового продукта добавьте, например, `<продукт>-desktop.webp` и `<продукт>-mobile.webp`. Мобильный файл каждого вида можно не задавать: тогда используется десктопный.

Рекомендуемые пропорции: десктоп 1144 × 701, мобильный 332 × 442. Для чёткого отображения экспортируйте в 2×. Изображение заполняет внутреннюю область рамки через `object-fit: cover`, поэтому важные элементы не размещайте у краёв.

Если `image` отсутствует, блок показывает плейсхолдер «Изображение» из макета. Рамка и внутренняя область с `backdrop-filter` задаются стилями компонента; они не должны входить ни в фон, ни в скриншот. Запечённый фон содержит декоративную ленту и свечение, но не экран и не заголовок.
