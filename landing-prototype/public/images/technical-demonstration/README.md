# Иллюстрация технического блока

Текущие готовые изображения: `demonstration block_desktop.png` для десктопа и `image_mobile.png` для мобильного экрана. В них уже запечены схема и зелёное свечение; карточка, заголовок и описание создаются кодом.

Затем в `content/geoflow-logistics-preview.ts` у `technicalDemonstration` добавьте:

```ts
image: {
  desktop: "/images/technical-demonstration/demonstration block_desktop.png",
  mobile: "/images/technical-demonstration/image_mobile.png",
  alt: "Краткое описание иллюстрации",
  layout: "showcase",
  ambientGlow: "rgb(31 120 46 / 22%)",
},
```

Для другой картинки укажите её путь в `desktop`, при необходимости отдельный `mobile`, и уберите `layout` и `ambientGlow`. По умолчанию блок сохраняет пропорции файла и показывает его целиком без обрезки и специальных смещений. Ширина следует линии текста (20 px от краёв карточки на мобильном, 48 px на десктопе), высота ограничена 320 px на мобильном и 497 px на десктопе. Если у файла большие прозрачные поля, их нужно убрать в самом файле для точного совпадения видимого содержимого с линией текста. Очень широкую схему лучше дополнить мобильным вариантом, чтобы подписи остались читаемыми. Если изображение чисто декоративное и полностью повторяет текст, используйте `alt: ""`.

`layout: "showcase"` оставьте только для текущих PNG: он включает их индивидуальное позиционирование. `ambientGlow` добавляет цветной слой за текущим PNG и плавно гасит его правый край на мобильном экране. Область этого макета: 1072 × 497 px на десктопе и 303 × 239 px при ширине экрана 375 px. При замене визуала проверяйте отступ 36 px от текста и отсутствие горизонтальной прокрутки.
