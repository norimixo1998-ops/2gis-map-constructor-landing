# Паспорта секций

Названия и ID типов секций совпадают с [каталогом и правилами сборки](landing-blocks-spec.md) и [корневым README](../README.md). ID `S01`–`S14` обозначают тип, а не порядок на странице: последовательность задаётся ТЗ конкретного лендинга. Технические имена файлов и React-компонентов связаны с типами через каталог; [правила именования](file-naming-conventions.md) описывают формат новых путей.
