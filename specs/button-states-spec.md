# Кнопки лендингов

Правила действуют на десктопе и мобильных ширинах. Для текстовых кнопок используется существующий Suisse Intl Medium: `font-weight: 500`, `font-size: 16px`, `line-height: 24px`.

| Вариант | Обычное состояние | Hover |
| --- | --- | --- |
| Зелёная primary | `#12951a`, белый текст | фон `#00830c`, белый текст |
| Полупрозрачная secondary | белый фон с непрозрачностью 12%, белый текст | белый фон с непрозрачностью 24%, белый текст |

В hero сохраняется размытие фона у secondary. Белые кнопки на зелёных блоках являются инверсным вариантом с собственным hover. Кнопки с иконкой без текстовой подписи не требуют текстовых параметров.
