# Сборка акции «ГеоПоток: Логистика» из библиотечных блоков

Маршрут `/geoflow-holiday` использует данные из [`content/geoflow-holiday.ts`](../landing-prototype/content/geoflow-holiday.ts). Порядок и выбор секций для текущего предпросмотра:

| Позиция по ТЗ | Тип | Содержание акции | Компонент и состояние |
| --- | --- | --- | --- |
| 1 | S01 Первый экран | Оффер акции | `Hero`, вариант 1; иллюстрация ГеоПотока для десктопа и мобильного. |
| 2 | S05 Сферы применения | Для кого подходит сервис | `AudienceScenarios`; названия сфер без пояснений, изображение пока плейсхолдер. [Паспорт](audience-scenarios-spec.md). |
| 3 | S02 Ключевые тезисы | Условия акции | `MainValues`; новые клиенты, три месяца, до пяти курьеров. [Паспорт](main-values-spec.md). |
| 4 | S06 Техническая демонстрация | Возможности сервиса | `TechnicalDemonstration`; визуал пока плейсхолдер. [Паспорт](technical-demonstration-spec.md). |
| 5 | S07 Шаги запуска | Как начать | `StartWork`; три шага, текст карточек — Suisse Intl Regular 18/26 px. |
| 6 | S09 CTA с кнопкой | Саморегистрация | `IntermediateCta`; после шагов, перед FAQ, одна кнопка пока отключена. [Паспорт](intermediate-cta-spec.md). |
| 7 | S10 Вопросы и ответы | Вопросы об акции | `Faq`; ответы пока из черновика условий. |

CTA использует кнопку вместо формы: действие в брифе — саморегистрация. Заголовок: «Подключите своих курьеров и планируйте на своих заказах». Блок стоит перед FAQ по структуре этого ТЗ: действие предложено сразу после шагов, ответы на вопросы идут ниже. Пока нет рабочего URL и подтверждённой выдачи промо-лицензии, кнопка отключена. Перед публикацией нужны утверждённые условия акции, визуал для блока возможностей и проверка промо-регистрации.
