# Hero, вариант 1 — иллюстрация 3D

Отдельный паспорт исходного Hero с текстом и кнопками слева от продуктовой иллюстрации на широком экране и иллюстрацией перед текстом на узком. Компонент: [`Hero.tsx`](../landing-prototype/components/hero/Hero.tsx) и [`Hero.module.css`](../landing-prototype/components/hero/Hero.module.css). Вариант с сеткой, свечением и широкой рамой описан отдельно в [паспорте Hero 2](hero-variant-2-spec.md).

Утверждённые фреймы: [десктоп 1440 px](https://www.figma.com/design/2GackEUWd1sfbXBU0OUElS/Конструктор?node-id=2-5732) и [мобильный экран 375 px](https://www.figma.com/design/2GackEUWd1sfbXBU0OUElS/Конструктор?node-id=3-13251). Размеры ниже описывают текущую реализацию; промежуточные ширины и точка переключения выбраны для рабочего адаптива.

## Назначение и состав

Первый экран называет продукт, кратко объясняет его пользу и предлагает одно или два действия. На странице используется один Hero и один H1. Состав блока: тёмный фон `#192025`, иллюстрация, H1, описание и ссылки-кнопки. Тексты и кнопки остаются HTML, иллюстрация передаётся отдельным файлом. Иллюстрация не должна перекрывать текст или терять значимые детали.

Данные компонента:

| Поле | Правило |
| --- | --- |
| `title` | Обязательный H1. `titleBreakAfter` при необходимости добавляет мягкую возможность переноса после указанного фрагмента, сохраняя текст без изменений. |
| `description` | Обязательное описание под H1. |
| `actions` | Количество кнопок определяется ТЗ конкретной страницы. Если указано одно действие, показывается только зелёная `primary`. Если в ТЗ указано второе действие, добавляется `secondary`. Порядок двух кнопок берётся из ТЗ и сохраняется на всех ширинах. У каждой кнопки свои `label`, `href` и необязательный `target`; ссылки открываются в текущей вкладке, если не указано иное. |
| `media` | Десктопный файл обязателен; мобильный необязателен. Для каждого задаётся `placement: "contain"` или утверждённое для конкретного ассета `"cover"`, при необходимости `position`. Смысловому изображению нужен непустой `alt`, декоративному — пустой. `animation: "float"` включает движение иллюстрации. |

Контент конкретной страницы хранится отдельно от компонента, например в [`map-constructor.ts`](../landing-prototype/content/map-constructor.ts) и [`geoflow-logistics-preview.ts`](../landing-prototype/content/geoflow-logistics-preview.ts). Изображения размещаются в [`public/images/hero/`](../landing-prototype/public/images/hero/). Если мобильный файл не передан, используется десктопный файл и его способ размещения.

## Десктоп: от 992 px

| Элемент | Правило |
| --- | --- |
| Контентная область | Ширина до 1168 px по центру экрана; на меньших ширинах боковые поля по 16 px. |
| Композиция | Две колонки: текст и действия слева, иллюстрация справа; вертикальное выравнивание по центру. Колонки гибкие, соотношение `1.32fr : 1fr`, промежуток от 32 до 61 px. |
| Отступ сверху | 80 px от начала Hero после Header. У блока нет фиксированной высоты. |
| H1 | Suisse Intl Medium, 56/68 px, выравнивание влево. |
| Описание | Suisse Intl Regular, 16/24 px; отступ от H1 — 20 px. |
| Кнопки | Отступ от текстовой группы — 40 px; расположение в строку с переносом при нехватке места, промежуток 16 px. Минимальная высота 56 px, внутренний отступ 16 px по вертикали и 20 px по горизонтали, радиус 12 px. `secondary` — белый 12%, `primary` — зелёный `#12951a`. |
| Иллюстрация | Занимает правую колонку, область с пропорцией `485:399`. Файл показывается по заданным `placement` и `position`. |

## Мобильная композиция: до 991 px

На ширинах ниже 992 px используется один столбец в порядке **иллюстрация → H1 → описание → кнопки**. Отдельной планшетной композиции для этого варианта нет. В 375 px контентная область равна 343 px, то есть остаётся по 16 px с каждой стороны; на других ширинах она заполняет доступное пространство с теми же полями.

| Элемент | Правило |
| --- | --- |
| Отступ сверху | 40 px от начала Hero после Header. |
| Иллюстрация | Первая в потоке, ширина до 600 px по центру; область с пропорцией `342:230`. На 375 px ширина области 343 px. |
| Текстовая группа | Через 40 px после области иллюстрации; H1 и описание выровнены влево по краю контентной области. |
| H1 | Suisse Intl Medium, 40/44 px. |
| Описание | Suisse Intl Regular, 14/20 px; отступ от H1 — 16 px. |
| Кнопки | Через 32 px после описания; одна или две ссылки занимают всю ширину контентной области и стоят вертикально с промежутком 16 px. Стили и минимальная высота кнопок такие же, как на десктопе. |

Точка 992 px — решение прототипа по вместимости двух кнопок и иллюстрации, а не значение, извлечённое из Figma. Между фреймами 375 и 1440 px размеры меняются плавно. При замене ассета нужно проверить его читаемость на 375, 768, 960 и 1440 px. Для карт, интерфейсов и смысловых композиций предпочтителен показ целиком; `cover` и точка фокуса требуют отдельного утверждения.

## Длинный текст и движение

H1, описание и подписи кнопок переносятся без многоточий и ограничения числа символов. Высота Hero растёт вместе с содержимым, интервалы между элементами сохраняются. Если описание делает блок чрезмерно высоким или подпись кнопки занимает более двух строк, текст отправляется на редактуру без автоматического сокращения.

Для лендинга Конструктора карт в данных включён `media.animation: "float"`: иллюстрация за 4 секунды линейно перемещается на 25 px вниз и обратно, бесконечно, без изменения геометрии блока. При `prefers-reduced-motion: reduce` движение отключается. На других страницах анимация появляется только при явном включении.

## Подключение и проверка

Маршрут [`/`](../landing-prototype/app/page.tsx) использует этот Hero с данными Конструктора карт. Второй вариант доступен отдельно на `/hero-variant-2-preview`; оба компонента остаются в проекте. При наполнении новой страницы проверить один H1, перенос текста, работу ссылок, порядок действий, `alt`, наличие мобильного ассета и отсутствие горизонтальной прокрутки. Для текущего примера основные проверочные ширины: 375, 390, 768, 960, 992, 1024 и 1440 px.
