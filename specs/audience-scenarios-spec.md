# S07 Сферы применения

**Статус:** необязательный блок. Добавлять в лендинг только тогда, когда он явно указан в ТЗ. Источник композиции — [Figma, фрейм 253:13093](https://www.figma.com/design/2GackEUWd1sfbXBU0OUElS/Конструктор?node-id=253-13093); конкретная секция внутри фрейма — `253:13620`. Реализация: `landing-prototype/components/audience-scenarios/AudienceScenarios.tsx`. Содержание задано отдельно для [акции](../landing-prototype/content/geoflow-holiday.ts) и [новой сборки акции](../landing-prototype/content/geoflow-hero-preview.ts).

## Назначение и данные

Блок перечисляет сферы применения или возможности продукта — в зависимости от страницы. Он не доказывает соответствие компаний условиям акции. Плашки содержат короткие названия без CTA.

| Поле | Правило |
| --- | --- |
| `id?` | Якорь секции; по умолчанию `audiences`. |
| `title?` | H2 над панелью. На `/geoflow-hero-preview` обязателен: «Команде доступ. Заказам маршрут. Вечеру праздник.» без принудительных переносов; строки формируются по ширине контейнера. На `/geoflow-holiday`: «Для кого подходит «ГеоПоток: Логистика»». |
| `description?` | Описание под H2. На `/geoflow-hero-preview` задано; на `/geoflow-holiday` не требуется. |
| `panelTitle?` | Заголовок внутри панели. На `/geoflow-hero-preview`: «Что входит». На `/geoflow-holiday` не задан. |
| `items[]` | Массив коротких названий сфер или возможностей. Пустой массив не выводит блок. Порядок задаёт ТЗ. |
| `image?` | Объект `{desktop, mobile?, alt}` для согласованных изображений. Без `image` виден подписанный плейсхолдер «Изображение» на всех ширинах; если мобильный файл ещё не передан, плейсхолдер сохраняется только в мобильной композиции. Файлы для новой сборки акции складываются в [`public/images/audience-scenarios/`](../landing-prototype/public/images/audience-scenarios/). |

На `/geoflow-holiday`: курьерская доставка; интернет-магазины; сервисные службы; дистрибуция; банки и доставка документов; B2B-перевозки.

На `/geoflow-hero-preview` блок стоит сразу после трёх плашек условий акции. H2 — «Команде доступ. Заказам маршрут. Вечеру праздник.» с естественным переносом: на десктопе первые два предложения занимают общую строку. Описание — «Подключите небольшую команду к 2ГИС ГеоПоток: Логистика и подготовьте маршруты следующего рабочего дня». Заголовок панели — «Что входит». Плашки: «Планирование и перепланирование маршрутов»; «Мобильное приложение с навигатором для курьеров»; «Выгрузка построенных маршрутов в Excel»; «Сравнение плана и факта». CTA внутри блока нет. Подключены `geopotok-image-desktop.png` от 900 px и `geopotok-image-mobile.png` до 899 px. Списки редактируются в контенте страниц и не зашиты в компонент.

Панель может быть самостоятельным блоком без внешнего заголовка и описания либо использоваться вместе с H2 и описанием. Внутренний заголовок панели во всех вариантах необязателен. Таким образом, отсутствие `panelTitle` не убирает внешний H2, а отсутствие H2 не требует добавлять внутренний заголовок. При отсутствии обоих заголовков секция получает доступное имя «Для кого».

Если есть описание, от нижней границы H2 до него всегда 20 px. От описания до панели — 36 px при ширине до 768 px включительно и 48 px при ширине больше 768 px. Без описания эти 36/48 px отсчитываются от H2 до панели.

## Композиция

| Элемент | Правило по доступному контексту Figma |
| --- | --- |
| Контейнер | До 1168 px по сетке библиотеки. |
| H2 и описание | Необязательная пара над панелью: белый H2 44/52 px и описание 16/24 px на десктопе. Любое из двух полей можно не задавать. |
| Панель | `#283136`, радиус 20 px; две области: список слева, изображение справа; внутренние поля сверху и по бокам около 36 px. Нижнего поля под изображением нет. |
| Заголовок панели | 30/38 px, если передан. |
| Плашки | Перенос строк по ширине, зазор 8 px, поля 16/24 px, радиус 20 px, светлый полупрозрачный градиент, текст 16/24 px. Не ссылки и не переключатели. |
| Изображение | Отдельный слот с верхними скруглениями 16 px. Его нижний край совпадает с нижней границей панели на десктопе и мобильном. Изображение заполняет слот с `object-fit: cover` и привязкой к левому краю, чтобы на промежуточных ширинах не обрезать телефон. Подменять плейсхолдер случайным визуалом продукта нельзя. |
| Узкий экран | Одна колонка, плашки переносятся, медиа идёт после списка и доходит до нижней границы панели; текст не обрезается. |

## Состояния и проверка

- Пустой `items[]`: блок отсутствует целиком. Если в ТЗ B03 не указан, сборщик его не добавляет.
- Без `image`: подписанный плейсхолдер остаётся только в предпросмотре; перед публикацией нужен утверждённый визуал или решение дизайнера о варианте без медиа.
- Проверить отсутствие горизонтальной прокрутки на 375, 768, 1024 и 1440 px, перенос длинных плашек и совпадение нижних границ медиа и панели.
- Перед публичным запуском сверить названия сфер с владельцем продукта и условия участия с владельцем акции.
