# S04 Сферы применения

**Статус:** необязательный блок. Добавлять в лендинг только тогда, когда он явно указан в ТЗ. Источник композиции — [Figma, фрейм 253:13093](https://www.figma.com/design/2GackEUWd1sfbXBU0OUElS/Конструктор?node-id=253-13093); конкретная секция внутри фрейма — `253:13620`. Реализация: `landing-prototype/components/audience-scenarios/AudienceScenarios.tsx`. Содержание для акции находится в [данных маршрута](../landing-prototype/content/geoflow-holiday.ts).

## Назначение и данные

Блок перечисляет сферы применения продукта. Он не доказывает соответствие компаний условиям акции. Плашки содержат **только названия сфер**: без пояснений, обещаний результата и CTA.

| Поле | Правило |
| --- | --- |
| `id?` | Якорь секции; по умолчанию `audiences`. |
| `title?` | Необязательный H2 над панелью. Для акции: «Для кого подходит «ГеоПоток: Логистика»». |
| `description?` | Необязательное описание под H2. Не требуется для акции. |
| `panelTitle?` | Необязательный небольшой заголовок внутри панели. Для акции не задан, чтобы не добавлять отсутствующий в рыбе текст. |
| `items[]` | Массив коротких названий сфер. Пустой массив не выводит блок. Порядок задаёт ТЗ. |
| `image?` | Объект `{src, alt}` для согласованного изображения. Пока его нет, виден подписанный плейсхолдер «Изображение». |

Текущий перечень акции: курьерская доставка; интернет-магазины; сервисные службы; дистрибуция; банки и доставка документов; B2B-перевозки. Список редактируется в контенте конкретной страницы и не зашит в компонент.

Панель может быть самостоятельным блоком без внешнего заголовка и описания либо использоваться вместе с H2 и описанием. Внутренний заголовок панели во всех вариантах необязателен. Таким образом, отсутствие `panelTitle` не убирает внешний H2, а отсутствие H2 не требует добавлять внутренний заголовок. При отсутствии обоих заголовков секция получает доступное имя «Для кого».

| Элемент | Правило по доступному контексту Figma |
| --- | --- |

| Заголовок панели | 30/38 px, если передан. |
| Плашки | Перенос строк по ширине, зазор 8 px, поля 16/24 px, радиус 20 px, светлый полупрозрачный градиент, текст 16/24 px. Не ссылки и не переключатели. |
| Изображение | Отдельный слот с радиусом 16 px. Подменять плейсхолдер случайным визуалом продукта нельзя. |
| Узкий экран | Одна колонка, плашки переносятся, медиа идёт после списка; текст не обрезается. Это адаптация реализации: мобильный вариант Figma пока не подтверждён. |

## Состояния и проверка

- Пустой `items[]`: блок отсутствует целиком. Если в ТЗ B03 не указан, сборщик его не добавляет.
- Без `image`: подписанный плейсхолдер остаётся только в предпросмотре; перед публикацией нужен утверждённый визуал или решение дизайнера о варианте без медиа.
- Проверить отсутствие горизонтальной прокрутки на 375, 768, 1024 и 1440 px и перенос длинной плашки «Банки и доставка документов».
- Перед публичным запуском сверить названия сфер с владельцем продукта и условия участия с владельцем акции.
